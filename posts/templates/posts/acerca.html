Acerca de este Blog

¿De qué se trata este proyecto?

Este blog es una plataforma web desarrollada desde cero con Python y Django, diseñada para compartir noticias, análisis de actualidad, economía y deportes.

El objetivo principal es ofrecer un espacio limpio y dinámico donde los usuarios registrados pueden crear, editar y administrar sus propias publicaciones de manera sencilla, mientras que los visitantes pueden explorar todo el contenido publicado.

Sobre el Autor

Proyecto desarrollado por ddebasto como parte de mi formación en desarrollo web backend. Construido utilizando arquitectura MVT (Modelo-Vista-Template), sistema de autenticación de usuarios, manejo de imágenes y paginación dinámica.
